Seguridad y Uso: AdminPanel

Matriz de Permisos

Módulo Admin Client
Vista Principal e Inventario
Gestión de Roles y Usuarios
Crear/Editar/Borrar (Todo)
Nota: El rol Client tiene permisos de solo lectura (`view_`) en el catálogo.

Usuarios y Roles

Permisos técnicos asignados:

view_roles create_roles update_roles delete_roles
Importante: Solo los usuarios con `manage_users` pueden modificar la estructura de acceso.

Categorías y Subcategorías

Control de jerarquía:

  • Subcategorías: Dependen de una Categoría activa.
  • Permisos: `view_subcategories`, `create_subcategories`, etc.
⚠️ Cascada: Al usar `delete_categories`, se desactivan sus hijos automáticamente.

Productos

Gestión del inventario final:

Lectura
Disponible para todos los roles (Admin/Client).
Escritura
Reservado para `create_products` y `update_products` (Admin).
